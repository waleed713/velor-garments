VELOR Garments - how to open
1. Keep ALL these files together in the same folder (do not move them into sub-folders).
2. Open the folder in VS Code and run index.html with the Live Server extension (recommended), or just double-click index.html in Chrome.
3. Lemon Milk font: put LemonMilk.otf in this same folder. Until then headings use Syncopate.
4. Edit these values:
   - script.js: WA (your WhatsApp number), PAY (bank / Easypaisa / JazzCash details), FREE_SHIP and SHIP_FEE (delivery rule)
   - script.js (layout part): footer email and links
Files: index.html, cart.html, checkout.html, style.css, script.js, logo.png
